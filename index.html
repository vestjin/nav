    云同步设置

    使用 GitHub Gist 跨设备同步书签。
    1. 前往 GitHub Tokens 创建 Token（仅勾选 gist 权限）并复制。
    2. 前往 Gist 创建一个新的私有 Gist（内容可留空），复制其 ID（URL 中最后一段）。
    3. 将 Token 和 Gist ID 填入下方，启用同步并保存。
    注意：请务必保管好您的 Token 和 Gist ID，系统不会自动创建。

    填写自建的 Cloudflare Worker 代理地址，可彻底解决国内抓取标题慢/失败的问题。（留空则使用公共代理）

    分组管理

    直接修改名称即可重命名分组（按回车或点击空白处生效）。删除分组会将组内书签移至“未分类”。

    📖 使用指南

    📌 核心功能

    • 书签管理 – 点击“＋”添加，支持名称、网址、分类、图标和笔记（📝 标记）。
    • 分组分类 – 左侧侧栏显示所有分组，点击切换；分组标题旁可折叠/展开，拖拽调整顺序。
    • 搜索过滤 – 实时搜索书签名称、网址、分类和笔记内容，回车直接使用搜索引擎。
    • 拖拽排序 – 拖拽卡片调整顺序（同组或跨组），拖拽分类标题调整分组顺序。
    • 元数据抓取 – 自动获取网页标题和 favicon，可手动刷新。
    • 笔记功能 – 每个书签可添加笔记，卡片右上角显示 📝 徽章提示。
    • 专注模式 – 点击时钟区域隐藏侧栏和书签，再次点击恢复。

    ☁️ 云同步

    • 使用 GitHub Gist 跨设备同步，需自行创建 Token 和 Gist ID。
    • 填写后启用同步，点击“拉取”或“推送”手动同步。
    • 本地修改后同步指示器会显示“●”，提醒您及时推送。

    📦 数据导入/导出

    • 导出为 JSON 备份，导入时按 URL 合并（不覆盖已有项）。
    • 所有数据存储在浏览器本地，卸载应用或清除浏览器数据会丢失，请定期导出备份。

    ⚙️ 其他

    • 快捷键：Ctrl+K 聚焦搜索框，Esc 关闭所有弹窗/专注模式。
    • 抓取代理：可配置自建代理加速标题获取，留空使用公共代理（可能受限）。

    ⚠️ 注意事项

    • Token 安全：GitHub Token 以明文存储在 localStorage，请勿在公共设备上使用。
    • Gist ID 必须手动填写：系统不会自动创建 Gist，请务必先创建并填入。
    • 数据备份：建议定期导出 JSON 备份，以防浏览器数据丢失。
    • 浏览器兼容：推荐使用最新版 Chrome/Edge/Firefox，拖拽功能需现代浏览器支持。
